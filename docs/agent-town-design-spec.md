# Agent Town · 设计规范（单一事实源）

> 本文档是 Agent 小镇的唯一视觉基准。每次改版前先读它，改完必须同步更新它。
> 状态：**待用户确认**（确认后才开始按此重建）。

## 1. 风格总锚

- **纯宝可梦 金/银（Pokémon Gold/Silver）** 像素世界观：明亮、饱和、圆润、治愈。
- 不是明制古风、不是暗色霓虹、不是 GB 冷色四阶灰。

## 2. 用户已确认的取舍（grilling 结论）

| 项 | 结论 |
|---|---|
| 保留（第一版 DNA） | ✅ 四季色板 + 昼夜循环、粒子特效、点击互动（加油 / grilling） |
| 不做（本轮明确简化） | ❌ GB 外框+扫描线+玻璃高光、明制袍服小人、工位小屋窗灯（不强行做） |
| 画面分辨率 | ✅ 逻辑画布 480×270（SNES 系），`image-rendering:pixelated` 放大显示，保留全屏 |

## 3. 画布与显示

- 逻辑画布：`480 × 270`。
- 显示：CSS 放大撑满主区（高度 84vh、最大 960px）+ 全屏按钮；`image-rendering: pixelated`。
- 性能：每帧重建离屏 `Uint32Array` 缓冲 → 手动转 RGBA → `putImageData`；DPR ≤ 2。
- 目标：打开即是完整明亮小镇（无 agent 也可见），**不黑屏**。

## 4. 色板（宝可梦金银调，四套季节变体）

基板：
- 描边 `#1a1c2c`（深墨）
- 草 `#58a858` / 亮草 `#8ac97f`
- 土路 `#e8c89a` / `#d8b26a`
- 天空 `#78c8f0` → 底部 `#b8ecff`
- 水面 `#4a8ee8`
- 树 `#3e8a4a` / `#2f6b33`
- 屋顶：红 `#f06a5a`、蓝 `#5888e0`、绿 `#58b858`（宝可梦式多色屋顶）
- 墙 `#fff8ec` / `#f0d090`
- 门窗：门 `#6b4423`、窗 `#ffd858`

四季变体只改：草/树/天空/屋顶高光/粒子类型（春樱 / 夏雨 / 秋叶 / 冬雪）。

## 5. 场景布局（480×270）

- 天空（0–46）：渐变 + 白天云朵 / 夜晚星星。
- 远山（34–46）：两层青色山影。
- 草地（46–底）：草色底 + 噪点 + 小花点（避开道路）。
- 道路：
  - 横向主路 `y=148..172`。
  - 纵向主路 `x=222..258`。
  - 路沿深色描边。
- 树木：5 棵三层圆润树冠树（带果子点缀）。
- 工位建筑：按阶段映射到 `STATION_POS`（宝可梦式小房，屋顶色=阶段色，奶油墙+门+窗）。
- 角色出生点、目标点：走到对应工位。

## 6. 角色（NPC）

- 画风：宝可梦金银风格的 Q 版训练家小人（**非明制袍服**）。
- 尺寸：约 12×16 像素；帽子+头发、眼睛、阶段色上衣/装饰、裤鞋。
- 动画：
  - 待机：轻微呼吸/点头。
  - 行走：2 帧左右腿交替。
  - 工作：上浮/挥动（阶段色+小工具符号）。
  - 加油：跳起欢呼帧。
- 阶段映射：`STAGE` 字典（refining/planning/plan-review/implementing/review/merge/audit/pm/design/split/blocked/needs-grilling/done/closed/ready/idle 等），每阶段 → 颜色 + 表情 + 符号 + 气泡文案。

## 7. 动效与粒子（保留项）

- 四季粒子：
  - 春：花瓣（粉）漂落。
  - 夏：雨丝 / 灰尘微光。
  - 秋：落叶（橙黄）漂落。
  - 冬：雪花下落。
  - 常驻：细小微光点（明暗呼吸）。
- 昼夜：色板明暗随时间变化；**下限钳制在明亮档，避免黑屏**；提供“昼夜开关”可选。
- 行走/工作/加油动画如上。
- `prefers-reduced-motion` 时关闭粒子与复杂动画。

## 8. 交互与数据（保留项）

- 点击 NPC：弹详情面板（阶段/任务/项目/状态/时长/动作）。
- **💗 加油**：爱心上飘 + 提示。
- **📍 定位**：跳转到该居民。
- **💬 grilling/问答**（规划中）：点击后调 agent-server `/agent/chat` 做一问一答（后续阶段实现，先留按钮位）。
- 底部/右侧 roster chips：显示在线居民，点击可定位/看详情。
- 数据源：agent-server `/agents`，每 2s 轮询；支持 `x-agents-finished` 计数。
- 空态：无 agent 时显示“小镇空闲”，但场景完整可见。

## 9. UI 外框

- 不用 GB 模拟屏幕（未勾选）。
- 采用**干净现代暗色工作台**外壳（与 dsh-web 一致）：`#0f1115` 背景、卡片、圆角，作为“播放器窗口”包住像素小镇。
- 顶部：标题 / 季节+时间 / 活跃计数 / 完工数 / 全屏按钮。

## 10. 技术约束

- 零外部资源（无图片/字体/库）。
- 单文件 HTML+CSS+JS，浏览器原生 Canvas2D。
- 行为契约不可变：`/agents` 轮询、`STAGE` 映射、点击详情、roster/log、加油/定位。

## 11. 迭代规则

1. 先读本 spec。
2. 每轮只改 1–2 个维度。
3. 改完同步更新本 spec。
4. 用户反馈只需 1–3 个词（“绿深点”“房圆点”“更像缘朱市”），由我推演落点。
5. 不整篇推翻；锚点漂移时回到本文档第 1–2 节。
