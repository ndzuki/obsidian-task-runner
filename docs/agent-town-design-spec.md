## 3. 画布与显示

- 逻辑画布：`960 × 540`。
- 显示：CSS 放大撑满主区（高度 84vh、最大 1680px）+ 全屏按钮；`image-rendering: pixelated`。
- 性能：每帧重建离屏 `Uint32Array` 缓冲 → 手动转 RGBA → `putImageData`；DPR ≤ 2；`prefers-reduced-motion` 关闭粒子与复杂动画。

## 4. 时间与光影

- `DAY_MS = 600000`（10 分钟一天）。
- `SEASON_DAYS = 8`（每季 8 天，约 80 分钟）。
- 起始 `TIME_OFFSET = 7.5 / 24 * DAY_MS`（约 07:30）。
- 一天阶段：
  - 清晨 05:30–07:30：低角度暖阳、长影、晨雾感。
  - 白天 07:30–17:30：明亮、短影。
  - 晚霞 17:30–19:30：橙红天空、长影。
  - 夜晚 19:30–05:30：月光/灯光、弱影。
- 太阳方位从东→南→西连续变化；影子长度 = 太阳高度角反比，影子方向 = 太阳方位反向。
- 色板随 `season` 变化：春樱 / 夏雨 / 秋叶 / 冬雪，只改草/树/天空/屋顶高光/粒子类型。

## 7. NPC 与互动

- 真实 agent：
  - 根据 stage/phase 映射到职业建筑/场地。
  - 工作状态：从出生点/休息点沿 A* 走到对应建筑入口，到岗后播放职业小动画。
  - 空闲状态：沿 A* 在小镇街道/广场自由游走；可自动与其他 NPC / 小精灵互动，或点击触发。
- 装饰居民（16–20）：
  - 5 个职业路人、2 个小孩、7 只小精灵/动物、3 只鸟、1 只猫。
  - 自动互动：两个 NPC 靠近且空闲 → 停顿打招呼（气泡）；小精灵跟随最近 NPC/agent；鸟沿上空正弦飞行。
  - 点击互动：路人挥手/鞠躬、小孩蹦跳、小精灵跃起+⭐/💗、猫蹭腿/“喵”气泡。
- 动态避让：其他 NPC 只做 8px 分离力，不触发实时 A* 重算。
- 速度：装饰居民约 26 px/s，真实 agent 约 30 px/s。

## 8. 交互与数据（保留并增强）

- 点击真实 agent：详情面板，显示阶段/职业建筑/任务/项目/状态/时长/动作/位置分区/工作台状态。
- **💗 加油**：爱心上飘 + 提示。
- **📍 定位**：跳转到该居民。
- **💬 grilling/问答**：调 agent-server `/agent/chat` 做一问一答（KB-first + 项目上下文）。
- 底部/右侧 roster chips：显示在线居民，点击可定位/看详情。
- 数据源：agent-server `/agents`，每 2s 轮询；支持 `x-agents-finished` 计数。
- 空态：无 agent 时显示“小镇空闲”，但场景完整可见。
- 顶部状态条：季节、日期、当前时段（清晨/上午/午后/黄昏/夜晚）、太阳角度、活跃/完工数。

## 10. 技术约束

- 零外部资源（无图片/字体/库）。
- 单文件 HTML+CSS+JS，浏览器原生 Canvas2D。
- A* 碰撞网格：12px/格，960×540 → 80×45；建筑/树/水/大花坛为静态障碍。
- 行为契约不可变：`/agents` 轮询、`STAGE` 映射、点击详情、roster/log、加油/定位/问答。
