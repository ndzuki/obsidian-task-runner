# 玩法与操作

ISO-CITY '98 的玩法**只有地图编辑与城市建造**：没有财政、没有分区需求、没有失败条件。人口与岗位只是状态栏上的观测量，唯一的「模拟」是可选的城市成长（临街建筑升档）。

---

## 1. 工具

工具栏在底部面板左侧 3x3 网格，`1` ~ `9` 依次选择。

| # | id | 名称 | 提示 | 行为 |
| --- | --- | --- | --- | --- |
| 1 | `inspect` | 查看 | 点击建筑看信息 | 只读：显示该格建筑（名称 / 人口 / 岗位）或地表（名称 / 海拔），不改数据 |
| 2 | `raise` | 抬高 | 拖拽抬升地形 | 笔刷范围内高度 +1（上限 `MAX_HEIGHT = 6`）；水面（海拔 0）不受影响 |
| 3 | `lower` | 降低 | 拖拽下沉地形 | 高度 -1；若降到 0 及以下则**下沉为水**：清除建筑与道路、地表改为水面、高度归 0。水面格忽略 |
| 4 | `level` | 整平 | 整到首次点的高度 | 以**本次拖拽起点的海拔**为目标，把笔刷范围内所有陆地整到同一高度（水面格跳过） |
| 5 | `terrain` | 地表 | 涂抹地表类型 | 在下方面板选地表类型后涂抹 |
| 6 | `road` | 道路 | 拖拽铺路或铁路 | 放置当前道路类型（0 号键的「无」不存在，用拆除工具清路） |
| 7 | `build` | 建筑 | 下方选建筑后放置 | 显示分类页签 + 建筑目录，按住布置 |
| 8 | `prop` | 绿化 | 种植树木与小品 | 目录固定为植被类道具（阔叶树 / 针叶树），不需要分类页签 |
| 9 | `bulldoze` | 拆除 | 清除建筑与道路 | 优先删建筑；该格没有建筑则清道路。**不动地形**（降地形请用「降低」或「地表→水面」） |

**笔刷半径**用 `[` / `]` 在 0 ~ 4 之间调整（`state.brush`，默认 1）。笔刷只作用于 `raise` / `lower` / `level` / `terrain` 四个工具，判定是圆形：`dx² + dy² <= r² + r`（比严格的圆略胖，让 r=1 时得到 5 格十字而不是 4 格菱形）。`road` / `build` / `prop` / `bulldoze` 始终单格。

**拖拽**。左键按下开始一笔（`runner.begin`），拖动时用 Bresenham 直线补齐中间格（`line()`，上限 4096 格防止死循环），松开结束。右键按下即「拆除」语义：对建筑/道具工具是删掉该格对象，对地形工具也是删对象（`end()` 之前的 `mods.erase` 分支）。

**放置校验**。`build` 与 `prop` 落地前调 `city.canPlace`：

| 条件 | 说明 |
| --- | --- |
| 全部格在地图内 | 越界直接失败 |
| 无既有建筑占用 | `occ[i] > 0` 失败 |
| 无道路 | `road[i] > 0` 失败 |
| 地面平坦 | `requireFlat`（建筑为 true，道具也是 true，因为 `canPlace` 的默认就是 `flat !== false`） |
| 非水面 | `allowWater` 只有「交通」类建筑才为 true；本目录里交通类没有建筑原型，所以实际上水上是种不了东西的 |

放置失败会提示「此处无法放置」，不消耗任何东西。

## 2. 地形与海岸线规则

城市数据模型是 64x64 的**高度场 + 地表表 + 道路表 + 单体占用表**（`web/js/city.js`）。地图开局的默认大小是 64x64，生成后固定；高度范围 `0 ~ MAX_HEIGHT(6)`。

### 地表类型

`TERRAIN` 表的 id 与存档顺序绑定，只能追加不能重排：

| id | key | 名称 | 瓦片 |
| --- | --- | --- | --- |
| 0 | `grass` | 草地 | `terrain.grass`（3 变体） |
| 1 | `meadow` | 深草地 | `terrain.meadow`（3） |
| 2 | `dirt` | 裸土 | `terrain.dirt`（2） |
| 3 | `sand` | 沙地 | `terrain.sand`（2） |
| 4 | `rock` | 岩石 | `terrain.rock`（2） |
| 5 | `gravel` | 砾石 | `terrain.gravel`（2） |
| 6 | `farm` | 农田 | `terrain.farm`（2） |
| 7 | `pave` | 铺装 | `terrain.pave`（2） |
| 8 | `concrete` | 水泥 | `terrain.concrete`（2） |
| 9 | `water` | 水面 | `terrain.water_f0` ~ `_f3`（4 帧动画） |

**id 9 是硬编码的水面判定**（`isWater`、`WATER_HEIGHT = 0`、多处 `terrain === 9` 判断），不是数据驱动的。新增地表请追加在 9 之前并同步修改判定，或干脆不要碰水面 id。

### 水面、抬升、侧壁

- **水面**：海拔固定 0，且是「不可施工介质」——`raise` / `level` 跳过水面格，`lower` 跳过水面格，`road` 与建筑放置都拒绝水面格。把水面改成陆地只有一条路：用「地表」工具涂任意陆地类型，`paintTerrain` 会自动把它抬到海拔 1（做出岸线）。
- **下沉为水**：用「降低」把陆地降到 0 时会连带清掉该格建筑、道路、并改成水面（`lower` 分支）。旧的水面瓦片下面不需要任何处理——地形层是平的，水的深度纯靠表面表达。
- **抬升**：`setHeight` 会 clamp 到 `0..6`。抬升不改变地表类型（把草地抬成台地，台顶还是草地）。
- **侧壁**：任何一格只要比 4 邻域的邻居高，高出部分就会在那一侧画出侧壁瓦片，逐层堆叠（`cliff.*`，高度 1 格/张）。侧壁材质由**该格的地表类型**决定：

  | 地表 | 侧壁前缀 |
  | --- | --- |
  | 草地 / 深草地 / 裸土 | `cliff.soil` |
  | 沙地 / 水面 | `cliff.sand` |
  | 岩石 / 砾石 | `cliff.rock` |
  | 农田 | `cliff.farm` |
  | 铺装 / 水泥 | `cliff.pave` |

  地图**边界之外视为海拔 0**，所以边缘不需要围一圈侧壁，只有被玩家抬高的地块会在边缘露壁。
- **道路**：三种类型（柏油路 / 土路 / 铁路）各有 16 张按 4 邻接连通掩码（bit0=+X、bit1=+Y、bit2=-X、bit3=-Y）预渲染的瓦片，运行时按 `roadMask` 自动选择，所以路口、直道、尽头都是自动成形的，玩家不需要手动拼。铺路时若该格有建筑会先删掉建筑；若该格海拔低于 1 会被自动抬到 1。铁路是 `road.rail`，用道砟 + 枕木 + 双轨绘制。

### 开局岛屿生成

`generateIsland(64, 64, seed)` 用三层确定性 value noise（xorshift32 洗牌 + 双线性平滑插值）+ 径向衰减生成地形：

```
r        = sqrt(nx²*1.05 + ny²*1.25) * 2          // 椭圆衰减
falloff  = max(0, 1 - (r*1.12)²)
nz       = n1(x/13, y/13)*0.66 + n2(x/6.5, y/6.5)*0.34
v        = falloff*0.78 + (nz - 0.5)*0.92
海拔       = 0 / 1 / 2 / 3 / 4  按 v > 0.32 / 0.50 / 0.70 / 0.90 分档
```

径向衰减刻意压得比噪声弱（系数 1.12、权重 0.78），否则整张图会变成一块高原而不是岛屿。随后两步收尾：

- `smoothCoast`：3x3 邻域内陆地 ≤ 2 的格子变水，陆地 ≥ 7 的格子若还漂在水里则变成陆地 → 抹掉孤立单格，海岸线连贯。
- `classifyTerrain`：海拔 0 → 水面；临水且海拔 ≤ 1 → 沙地；海拔 1 → 草地；海拔 2 → 按噪声在草地/深草地间分；海拔 3/4 → 岩石或砾石。

注意生成器只产出 0 ~ 4 的海拔，`MAX_HEIGHT = 6` 的两档只有玩家手工抬升才会出现。

## 3. 城市成长规则

城市成长默认开启（`P` 键或 `state.growth` 切换；存档里的 `growth` 偏好会恢复）。它**只是纯观感变化**：升档会改变人口/岗位数字，但不影响任何玩法平衡（没有税收、没有需求条）。

**触发**：每帧累计 `dt * speed`，超过 1.6 秒就尝试一次；每次尝试最多抽 3 个候选。

**候选**：`city.objects` 里 category 属于三条成长链之一的建筑。

| 链 | 顺序（低 → 高） |
| --- | --- |
| 住宅 | `house.small` → `house.suburban` → `house.townhouse` → `apartment.walkup` → `apartment.tower` |
| 商业 | `shop.corner` → `shop.row` → `office.block` → `office.tower` |
| 工业 | `warehouse` → `factory` |

**升档条件**（三条全过才升级）：

1. 当前建筑在链中且不是链尾；
2. **临街**：`hasRoadNear` —— 从 `(x-1, y-1)` 到 `(x+fw, y+fh)` 的矩形（含建筑自身一格的外扩）里存在任一道路格；
3. **放得下**：新建筑的占地必须能覆盖在**旧建筑当前位置**上——新占地每一格都要在地图内、`occ` 为空或属于旧建筑自己、`road == 0`、且高度与旧建筑所在地面高度一致。也就是说升档不会重新选址，只会原地「长大」；占地变大而旁边没空地时这次升级就失败（另两次机会继续抽别的候选）。

**升级动作**：`city.removeAt(旧位置)` → `city.place(新原型, 同位置)`，新变体用 `assets.pickVariant` 随机挑（所以同一栋楼升档后会换一个外观变体）。

**链设计的实际约束**：链内相邻两级的占地是同一或更大，因此只有「占地不变」或「旁边恰好有空地」时才升得动。住宅链里 `house.small`(1x1) → `house.suburban`(1x1) → `house.townhouse`(2x1) → `apartment.walkup`(2x2) → `apartment.tower`(2x2)，实际可稳定观察到的升档是前两级与最后一级（2x2 → 2x2）；中间两步要求玩家周围留了空地。

## 4. 存档与示例城镇

### localStorage

| key | 内容 | 写入时机 |
| --- | --- | --- |
| `isocity98.save.v1` | `city.toJSON()`：`{v:1, w, h, height[], terrain[], road[], objects[]}` | 只有 `Ctrl+S`（以及帮助对话框的「存档」按钮） |
| `isocity98.opt.v1` | `{crtMode, autoNight, growth, zoom}` | 每约 4 秒自动保存一次 |

**没有自动存档**：关掉页面再打开，会回到页面加载时读到的存档（首次运行是随机岛屿），期间未按 `Ctrl+S` 的改动会丢失。`Ctrl+O` 显式读档。

**对象记录**（`objects[]`）保存的是 `{name, sprite, label, category, x, y, fw, fh, level, pop, jobs, cost, variant}`：`name` 是原型名、`sprite` 是实际落地时挑中的变体精灵名。读档时 `City.fromJSON` 重建 `occ` 占用表（逐个对象按占地回填）并把 `version` 自增，于是渲染缓存立即失效重建。

存档结构兼容性靠 `v: 1` 与「地表 id 只能追加不能重排」两条约定维护；`fromJSON` 没有做版本迁移，字段缺失会直接抛错（`height.set(...)` 对长度不匹配的数组会静默截断，风险由 `w/h` 一致性保证）。

### 示例城镇

`ISO.demo()`（控制台调用，或注入 `--eval "ISO.demo()"` 给 `scripts/shot.mjs`）会一键生成一座示例小城 `buildDemoTown()`，等价于玩家的正常操作顺序：

1. 统计地图中心 ±10 格内的常见海拔（跳过水面），取众数并 clamp 到 `1~3` 作为整平目标；
2. 把 ±10 格整平到目标高度（保留水面）；
3. 中心 5 格以内铺成「铺装」（`terrain.pave`，id 7），其余铺成草地；
4. 铺十字主干道 + 一条东西支路；
5. 按固定位置表落 20 座建筑（办公塔、写字楼、沿街商铺、市政厅、公寓、独栋、别墅、口袋公园、仓库、工厂、学校……），放不下的静默跳过并计数；
6. 随机撒 44 棵树（避开道路与已有建筑），最后提示「已生成示例城镇（N 座建筑）」。

`window.ISO` 还暴露了 `state` / `city` / `world` / `view` / `assets` / `crt` 与 `newMap(seed)`，方便控制台调试与自动化截图断言。

## 5. 模拟与状态栏

- **时间**：`state.clock` 从 08:00 开始，每真实秒推进 `60 * speed * 0.6` 游戏分钟（`speed = 1` 时约 36 游戏分钟/秒），到 1440 归零并 `day++`。时间**不存档**，读档/刷新都从 08:00 重新开始。
- **速度档**：`state.speed ∈ {0,1,2,3}`，通过点击状态栏 `x ∈ [96,100)` 循环。`0` 直接跳过整个 `simulate`（时间、成长、水面动画都停）。
- **自动昼夜**：开启时按 `hour < 6 || hour >= 19` 判定夜间，会自动切换 `assets.night`（触发整图缓存重建）。关闭后用空格或点击状态栏 `x ∈ [566,600)` 手动切。
- **状态栏**（640x14）：`ISO-CITY 98` 标识、人口、岗位、建筑、道路、当前工具/所选建筑、白天/夜间、`HH:MM`、FPS。FPS > 45 时用暗色，否则用警示色。
- **小地图**（右下 72x87）：1 像素 = 1 格，按地表与建筑分类着色（道路灰、公园/植被绿、住宅砖红、商业金黄、工业石灰、其余市政青色），高度越高越亮（`1 + h*0.06`）。点击小地图可把相机移过去；视口取景框由相机四角反算，用白框标出。
- **信息框**（`x=462, w=94`）：未选物品时显示当前工具提示，选了建筑则显示造价 / 人口 / 岗位 / 占地 / 类型。
